# أصول التطبيق

الملفات دي **مطلوبة قبل أول build** ولسه مش موجودة:

| الملف | المقاس | الاستخدام |
|---|---|---|
| `icon.png` | 1024×1024 | أيقونة iOS + المصدر لباقي المقاسات |
| `adaptive-icon.png` | 1024×1024 | الطبقة الأمامية لأيقونة Android التكيّفية (خلي فيها هامش آمن ~20%) |
| `splash.png` | 1284×2778 | شاشة البداية |

كلها PNG بخلفية شفافة ما عدا `splash.png`.
اللون الأساسي `#16a34a` والحرف "ف" — نفس هوية الموقع.
